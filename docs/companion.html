Decentralized CBO: the linear model

Interactive companion to the paper.

This page solves the iteration

P′ = (1−a)P + aZ,    Z′ = −aP + WZ + aZ,    a = λ dt,

where P holds the positions of the N nodes, Z the tracking variables and W the mixing matrix. It is decentralized CBO with zero noise and each node collapsed onto its consensus point. N nodes and M particles per node as in the paper; M does not enter here.

On a ring W is circulant with eigenvalues γk = θ + (1−θ)cos(2πk/N), where θ is the self-weight, and the iteration splits into 2×2 blocks indexed by k.

Mode shapes: eigenvectors of L

W = I − dt L, γkL = (1 − γkW)/dt, envelope exp(−γLt/2). On a ring the eigenvectors are the Fourier modes cos(2πkj/N), sin(2πkj/N).

Modal amplitudes

μi(t) = ⟨P(t), vi⟩ over the real orthonormal eigenbasis, so P(t) = ∑i μi(t) vi. Each μi follows the 2×2 block of its own mode.

Continuous time: L = (I − W)/dt = ((1−θ)/dt) Lrw — scaled by dt, not a fixed graph Laplacian; θ = 1 − dt puts its spectrum in [0, 2]. U′ = −CU with C = [[I, −I],[I, L−I]]; per eigenvalue ℓ of L, ν² + ℓν + ℓ = 0, complex for 0 < ℓ < 4, real part −ℓ/2.
